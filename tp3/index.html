Le langage SQL

1.1. Définition

Le langage SQL (Structured Query Language) est un langage permettant la création et la gestion d’une base de données relationnelle.

Il a été créé en 1986 et est issu du modèle relationnel inventé en 1970 par Mr Codd.

Il est utilisé dans des SGBDR comme Oracle, SQL Server, MySQL ou PostgreSQL.

1.2. Les différentes normes utilisées

  • SQL 89
  • SQL 92
  • SQL 2011
"SQL-92 définit trois niveaux de conformité : ENTRY, INTERMEDIATE et FULL."
